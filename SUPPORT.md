# Support

## Where to get help

| What you need | Where to go |
| --- | --- |
| A bug in the SDK or MCP server | [GitHub Issues](https://github.com/thyn-ai/telys-sdk/issues) with the `bug` label — include the package version, runtime version, and a minimal reproduction |
| A feature request | [GitHub Issues](https://github.com/thyn-ai/telys-sdk/issues) with the `enhancement` label |
| Usage questions, ideas, show-and-tell | [GitHub Discussions](https://github.com/thyn-ai/telys-sdk/discussions) |
| Real-time chat with the community | [Discord](https://discord.gg/w8NDsph9an) |
| Documentation | [docs.telys.ai](https://docs.telys.ai) |

Before filing an issue, please search existing issues and discussions — your
question may already have an answer.

## Security issues

**Never report a security vulnerability in a public issue, discussion, or
pull request.** Follow [SECURITY.md](./SECURITY.md): use GitHub Security
Advisories or email `security@algenta.ai`.

## Response expectations

Community support is provided on a best-effort basis by maintainers and other
community members. **There is no SLA for community support** — we triage
issues as time permits, prioritizing security reports (which have their own
response commitments in [SECURITY.md](./SECURITY.md)), data-loss bugs, and
regressions in the latest release.

Enterprise customers with a commercial agreement should use their
contracted support channel or contact community@algenta.ai to be routed.
